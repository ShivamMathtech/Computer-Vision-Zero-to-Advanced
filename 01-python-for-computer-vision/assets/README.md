# Chapter assets

All figures here are original plots produced from the repository's synthetic arrays. They contain no downloaded imagery or personal data.

- `pixel-lab-preview.png`: actual Pixel Lab output used as the chapter preview.
- `pixel-grid.png`: numeric grayscale grid for coordinate intuition.
- `channels.png`: RGB image and isolated red, green and blue planes.

Regenerate with `python scripts/make_learning_assets.py`. The synthetic source arrays are defined in `cvzero.synthetic`; data fixtures are recreated with `scripts/prepare_datasets.py`.
