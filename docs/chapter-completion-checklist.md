# Chapter completion gate

Copy this into a chapter's progress record. A checkbox is evidence-backed only when its file and validation are present.

- [ ] README contains learning goals, motivation and prerequisites
- [ ] Beginner explanation and intuition precede terminology
- [ ] Theory includes what, why, how, when, where and what next
- [ ] Important equations define symbols, intuition, a number, code and an application
- [ ] Focused notebooks follow every notebook-design section
- [ ] Basic Python/NumPy implementation is visible
- [ ] From-scratch implementation exists where educationally useful
- [ ] OpenCV or other library implementation is explained and compared
- [ ] Visualizations have meaningful labels, units and color conventions
- [ ] Experiments vary controlled parameters
- [ ] Beginner, intermediate and advanced exercises exist
- [ ] Separate real-world challenge has no immediate solution
- [ ] Mini project has an executable entry point and project documentation
- [ ] Common mistakes and useful error messages are included
- [ ] Interview questions cover six categories
- [ ] Primary references and any applicable paper review are included
- [ ] Data provenance, instructions and small offline fixtures are available
- [ ] Notebooks pass top-to-bottom execution in fresh kernels
- [ ] No undefined variables, personal paths or hidden downloads
- [ ] CPU/GPU requirements and optional dependencies are explicit
- [ ] Numerical, error-path and integration checks pass
- [ ] No fabricated metrics; results distinguish measured and expected output
- [ ] Next chapter and learning checkpoint are linked
- [ ] Main roadmap and progress status match the actual delivery
