# Community Code of Conduct

Treat learners and contributors with patience and respect. Critique ideas and code rather than people. Welcome questions, acknowledge corrections and avoid assumptions about someone's background.

Harassment, discriminatory language, threats, sexualized content directed at participants, doxxing and deliberate disruption are not acceptable. Respect privacy and use only data you have permission to share.

When a problem occurs, contact a repository maintainer through an available private contact on their profile. Do not publish private evidence or contact details in an issue. If no private contact is available, ask a maintainer for a private reporting channel without posting the allegation publicly.

Maintainers should review reports fairly, protect the reporter's privacy, explain decisions where appropriate and respond proportionately: correction, warning, temporary restriction or removal. Anyone involved in a report should recuse themselves from deciding it. This policy applies to repository spaces and official community interactions.
