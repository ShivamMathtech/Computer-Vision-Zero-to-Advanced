# Reporting software issues

For ordinary bugs, open an issue with a minimal synthetic example. For a vulnerability, use the repository hosting platform's private security reporting if enabled, or request a private maintainer contact. Never include access tokens or personal data in a public report.

This first release is a local educational toolkit, not an internet-facing service. It validates image shapes and paths and limits decoded image size. Later API chapters require their own deployment review, request limits, authentication, monitoring and model evaluation before real use.
