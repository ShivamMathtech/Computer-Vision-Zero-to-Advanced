# Beginner projects

Every project has a runnable educational baseline and a separately stated extension.

| Project | Chapter | Goal |
|---|---:|---|
| [Image Editor](image-editor/README.md) | 06 | Compare brightness, contrast, gamma and local enhancement with saved visual reports. |
| [Color Detector](color-detector/README.md) | 08 | Isolate a calibrated color interval and inspect its failure under low saturation. |
| [Edge Detector](edge-detector/README.md) | 13 | Compare explicit Canny stages with optimized derivatives and edges. |
| [Shape Detector](shape-detector/README.md) | 12 | Measure segmented shapes and distinguish geometric descriptors from category labels. |
| [Motion Detector](motion-detector/README.md) | 17 | Detect changes in a generated sequence and compare background adaptation. |
| [Webcam Filter](webcam-filter/README.md) | 15 | Process video frames consistently and extend the tested generated stream to a local camera. |
| [Document Scanner](document-scanner/README.md) | 07 | Estimate a planar warp from corners and inspect resampling artifacts. |

[Pixel Lab](pixel-lab/README.md) is the fully worked introductory image editor with image input and HTML reports.
