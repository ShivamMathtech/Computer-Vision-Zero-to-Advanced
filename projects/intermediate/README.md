# Intermediate projects

Every project has a runnable educational baseline and a separately stated extension.

| Project | Chapter | Goal |
|---|---:|---|
| [Face Detection System](face-detection-system/README.md) | 19 | Run an actual cascade API and explain why a synthetic face cartoon is not a face benchmark. |
| [OCR System](ocr-system/README.md) | 21 | Build a preprocessing and recognition baseline before running optional Tesseract. |
| [Object Counter](object-counter/README.md) | 12 | Count distinct segmented regions and analyze touching-object errors. |
| [Vehicle Detector](vehicle-detector/README.md) | 27 | Understand box evaluation and connect a trained object detector for real vehicle classes. |
| [Image Classifier](image-classifier/README.md) | 25 | Train and evaluate a small CNN before adapting a real ImageFolder dataset. |
| [Image Stitching](image-stitching/README.md) | 10 | Find correspondences and a robust planar transform from overlapping views. |
| [Camera Calibration](camera-calibration/README.md) | 16 | Estimate intrinsics from multiple board views and quantify reprojection residuals. |
| [Hand Gesture Controller](hand-gesture-controller/README.md) | 33 | Use scale-normalized landmarks and stable interaction states without automatic OS control. |
