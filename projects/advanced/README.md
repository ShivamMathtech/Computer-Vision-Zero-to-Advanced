# Advanced projects

Every project has a runnable educational baseline and a separately stated extension.

| Project | Chapter | Goal |
|---|---:|---|
| [YOLO Custom Detector](yolo-custom-detector/README.md) | 28 | Prepare labels, validate splits, train, evaluate, predict and export a selected YOLO model. |
| [Multi-Object Tracking](multi-object-tracking/README.md) | 36 | Associate detections to persistent temporary IDs and inspect missed-observation behavior. |
| [Semantic Segmentation](semantic-segmentation/README.md) | 31 | Train a dense foreground predictor and extend the label/loss contract to multiple classes. |
| [Instance Segmentation](instance-segmentation/README.md) | 30 | Separate touching objects and compare classical markers with an optional learned mask model. |
| [Pose Estimation](pose-estimation/README.md) | 32 | Decode heatmaps, compute angles and count complete motion cycles. |
| [Real-Time Surveillance Analytics](real-time-surveillance-analytics/README.md) | 53 | Build local scene analytics with anonymous IDs and numeric event logs. |
| [Industrial Defect Detection](industrial-defect-detection/README.md) | 26 | Compare frozen transfer and fine-tuning under a controlled domain shift. |
| [Autonomous Vision Pipeline](autonomous-vision-pipeline/README.md) | 53 | Integrate perception, monitoring and an API; this project contains no actuator or vehicle control. |
