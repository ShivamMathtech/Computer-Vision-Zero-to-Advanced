# Repository visuals

`learning-journey.png` is an original programmatically drawn curriculum map. It distinguishes the overall roadmap from the implemented first release. It is generated by `scripts/make_learning_assets.py` and uses no third-party imagery.

Chapter-specific figures are in `01-python-for-computer-vision/assets/`; executable notebook outputs show their own plots. Result previews come from the actual Pixel Lab implementation.
