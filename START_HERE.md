# Start here

This ZIP contains **all 53 chapters** of Computer Vision — Zero to Advanced, with 160 lesson notebooks, theory, code, exercises, mini projects, portfolio baselines and the local capstone.

1. Follow [setup instructions](docs/setup.md), including the detailed Windows commands if this is your first Python environment.
2. Run `python -m cvzero doctor` using your virtual environment's Python.
3. Run `python -m cvzero demo --output artifacts/first-run` and open the generated `report.html`.
4. Start JupyterLab with `python -m jupyter lab`.
5. Begin [Chapter 01](01-python-for-computer-vision/README.md) and work through its four notebooks.
6. Continue in order through the [complete chapter map](README.md#chapter-map), completing exercises and mini projects.
7. Integrate the later chapters in the [real-time platform](projects/capstone/README.md).

Default labs run on CPU and create their own inputs, except packaged handwritten digits and the OpenCV-bundled Haar cascade. No separate pretrained-weight or dataset download is required. Optional real-data/pretrained workflows and hardware limits are stated in [validation evidence](docs/VALIDATION.md).
